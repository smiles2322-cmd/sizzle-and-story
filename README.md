# Sizzle & Story

Cook the story. Make the meal.

A cozy anime cooking game where every dish is a real recipe you can cook at home. Version 1: the first playable story slice (Fluffy Pancakes) plus real recipe cards for six dishes.

Play: https://smiles2322-cmd.github.io/sizzle-and-story/

The playable site is stored as site.tgz.b64 (a base64 tar of the static app). The Publish workflow unpacks it to the gh-pages branch.
